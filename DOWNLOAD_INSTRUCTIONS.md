# How to Install BLITE on Windows

BLITE is currently unsigned, which means Windows SmartScreen will show a warning. This is normal for new applications and doesn't mean the software is harmful.

## Installation Steps

1. **Download** the installer from blite.chat
2. Windows will show "Windows protected your PC"
3. Click **"More info"**
4. Click **"Run anyway"**
5. The installer will proceed normally

## Why This Happens

New applications without an Extended Validation certificate trigger Windows SmartScreen. We're working on getting code signing in place to remove this warning.

## Is it Safe?

- Open source code available on GitHub
- Built from verified source
- No telemetry or tracking
- End-to-end encrypted messaging

You can verify the installer hash matches our published checksums at blite.chat/downloads/latest.yml
